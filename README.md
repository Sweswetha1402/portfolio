# Swetha Ponmudi — Premium AI Full-Stack Portfolio

A responsive, dependency-free portfolio website built from the supplied portfolio brief.

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

- End-to-end ownership flow
- Resume-supported impact metrics
- Beyond Writing Code lifecycle

- Case-study placeholders with no invented confidential details

## Content intentionally not fabricated

Verified LinkedIn, GitHub and resume URLs were not provided, so the contact area contains a clearly marked personalization note instead of invented links.

The case studies are placeholders because no project names or confidential details were provided.
